# Kuripp 📝

**Kuripp** is a minimal, privacy-first desktop application designed for seamless daily productivity. It combines task management and structured note-taking into a single, beautiful experience—keeping your data exactly where it belongs: on your own machine.

![Kuripp Preview](build/icon.png)

## ✨ Features

- 🌓 **Dual Themes**: Switch between premium Dark and Light modes.
- 🔍 **Global Search**: Find any task or note instantly with real-time filtering.
- 🔒 **Privacy First**: Local-only storage. No cloud, no accounts, no trackers.
- ⚡ **Offline Ready**: Works perfectly without an internet connection.
- 🎨 **Trendy Design**: Sophisticated glassmorphism aesthetic with smooth animations.

## 🛠️ Tech Stack

- **Framework**: [Electron](https://www.electronjs.org/)
- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS)
- npm

### Development
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production
To generate a standalone Windows installer (`.exe`):
```bash
npm run dist
```
The installer will be generated in the `dist-electron/` folder.
